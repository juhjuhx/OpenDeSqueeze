# Code of Conduct

OpenDeSqueeze aims for technically useful, respectful collaboration.

Expected behavior:

- Discuss code, behavior, evidence, and trade-offs directly.
- Reproduce bugs before escalating claims.
- Critique implementations without attacking people.
- Respect licenses, authorship, privacy, and security boundaries.
- Do not publish another person's sensitive logs, media, credentials, or identifying data.

Unacceptable behavior includes harassment, discriminatory attacks, deliberate disruption, spam, doxxing, and knowingly submitting malicious code.

Maintainers may edit, hide, lock, or remove contributions that materially violate these rules.
