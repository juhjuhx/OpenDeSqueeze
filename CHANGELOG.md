## [0.1.0] - 2026-09-06

### Added

- Batch photo/video selection through Android SAF.
- 1.33× / 1.50× / 1.55× / 1.80× / 2.00× and custom desqueeze.
- Preserve Width / Preserve Height geometry modes.
- JPEG / PNG / WebP Lossless photo export.
- AVC / HEVC / AV1 selection where supported.
- MediaCodec hardware/software capability scanning and runtime fallback.
- MediaExtractor → MediaCodec → OpenGL ES → MediaCodec → MediaMuxer video pipeline.
- Foreground media-processing service.
- Host tests and GitHub Actions Android build.
- Successful real-device conversion of photos/video.
